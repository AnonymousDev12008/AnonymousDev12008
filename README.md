I'm a self-driven developer from India with a strong interest in **cybersecurity**, **privacy tooling**, and **Python-based terminal applications**. I build stateful, functional tools that run entirely in the terminal — no fluff, no GUI dependencies, just precise, purposeful code.

My work gravitates toward:
